# Nuran Artisan Coffee

Aplikasi katalog produk UMKM Nuran Artisan Coffee berbasis Next.js 16 (App Router), Tailwind CSS 4, dan Supabase.

## Fitur Utama

- **Katalog & Detail Produk:** Menampilkan produk dari database Supabase, foto, kategori, format rupiah, dan status stok.
- **Pesan via WhatsApp:** Tombol pemesanan WhatsApp otomatis memuat nama produk, varian ukuran, harga, jumlah, dan total harga.
- **Keranjang & Checkout:** Pengelolaan keranjang multi-item dan checkout massal ke WhatsApp toko.
- **Admin Panel:** Manajemen produk, upload foto Supabase Storage, kelola kategori, banner promo, moderasi ulasan, ekspor/impor CSV, dan log aktivitas.
- **Fitur Cerdas & SEO:** Asisten AI Tanya Jawab (Gemini API), sitemap.xml, robots.txt, dynamic Open Graph metadata, PWA, dan Dark Mode.

## Instalasi & Menjalankan

```bash
npm install
npm run dev
```

Build produksi:

```bash
npm run build
npm run start
```
